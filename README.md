# Luma

一个本地优先的 Android 生活记录 + AI 陪伴应用。

## 项目简介

Luma 是一个运行在 Android 设备上的个人生活管理应用，核心特点是**数据完全存在用户自己的手机本地**，不经过任何服务器中转。

## 目前已经做好的功能

- 与 AI 的对话（需要用户自己填入 API Key，直接连接到对应的 AI 服务商，不经过 Luma 自己的服务器）
- 对话时间轴、对话摘要、主题档案
- 待办事项
- 备忘录 / 收藏夹
- 健康记录
- 生理期记录
- 信件
- 日记
- 每日打卡记录
- 记账（独立开发中，尚未合并进正式版本）

## 技术架构

- 外壳：Android 原生（Kotlin），一个 WebView 容器
- 内部功能：原生 HTML / CSS / JavaScript 实现（不依赖前端框架）
- 数据存储：IndexedDB（浏览器本地数据库），全部数据留在设备本地
- 最低支持：Android 8.0（API 26）
